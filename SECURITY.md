# Security

This policy covers every repository in the Azoth Engine organization.

## Reporting a vulnerability

Please do not report a security vulnerability through a public issue, discussion, or pull request. Instead, please email ianpike98cs@gmail.com with "Azoth security" in the subject line.

It helps if the report says which repository and files are involved, the tag or commit where you found it, and what kind of issue it is. Also include the steps to reproduce it and any configuration it needs. If you have proof of concept code or an idea of how it could be exploited then please send that too.

Azoth is currently maintained by one developer so I can not promise a response time. I do read every report. Please also give me a reasonable amount of time to fix the issue before you share it publicly.
